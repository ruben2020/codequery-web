# codequery-web
================

This is a web-based user interface for [CodeQuery](https://github.com/ruben2020/codequery).

[CodeQuery](https://github.com/ruben2020/codequery) is a tool to index, then query or search C, C++, Java, Python, Ruby, Go and Javascript source code.

It builds upon the databases of [cscope](http://cscope.sourceforge.net/) and [Exuberant ctags](http://ctags.sourceforge.net/). It can also work with [Universal ctags](https://github.com/universal-ctags/ctags/), which is a drop-in replacement for Exuberant ctags.

The databases of cscope and ctags are processed by the `cqmakedb` tool to generate the CodeQuery database file (`cq.db`). The tool cscope works with C, C++ and Java. The database of cscope can also be generated by [pycscope](https://github.com/portante/pycscope) for Python and [starscope](https://github.com/eapache/starscope) for Ruby, Go and Javascript.

The CodeQuery database file can be queried on a web browser using **codequery-web**. It makes use of the CodeQuery CLI tool `cqsearch` to perform high-performance queries, and provides:
* A modern web interface with dark theme
* Interactive search with exact and fuzzy matching, path filters, and all 11 CodeQuery query types
* Results table with line previews and truncated paths directly linking into source code lines
* Fast directory browser with an interactive desktop-like folder address breadcrumb bar
* Syntax-highlighted code viewer (C, C++, Python, JavaScript, Go, Java, C#, Markdown) with clickable symbol hyperlinks for instant navigation and symbol lookups


## What types of query can I make with this software?

* Symbol
* Function or macro definition
* Class or struct
* Files including this file
* Functions calling this function
* Functions called by this function
* Calls of this function or macro
* Class which owns this member or method
* Members and methods of this class
* Parent of this class (inheritance)
* Children of this class (inheritance)

## Which platforms are supported?

It has been tested on Linux 64-bit and Windows 10/11 64-bit. It runs anywhere Python 3.10+ or Docker is supported, including macOS.


## What are the prerequisites or dependencies that I must install?

You need to install the following:

* [Python](https://www.python.org/) 3.10 or higher (or Docker)
* [CodeQuery](https://github.com/ruben2020/codequery)
* Other tools to support CodeQuery like [cscope](http://cscope.sourceforge.net/), [ctags](http://ctags.sourceforge.net/), [pycscope](https://github.com/portante/pycscope) or [starscope](https://github.com/eapache/starscope), depending on your specific need.

If you have installed CodeQuery correctly, `cqsearch` should be accessible on a terminal window from any folder i.e. it's on PATH. This is required.


## How do I prepare my source code for use with this software?

The software looks for the target source code and the CodeQuery database file (`cq.db`) inside the `share/` folder by default (or any custom folder provided via the command-line argument when starting `wsgi.py`).

Let me provide an example here on how to prepare the source code of CodeQuery itself.

In Linux or Mac, follow these steps for C/C++ source code:

```bash
cd ~/repo/codequery-web
mkdir -p share
cd share
git clone https://github.com/ruben2020/codequery.git .
```

Then generate the cscope and ctags databases, and combine them into `cq.db`:

```bash
find . -iname "*.h" -o -iname "*.hpp" -o -iname "*.hxx" -o -iname "*.hh" -o -iname "*.c" -o -iname "*.cpp" -o -iname "*.cxx" -o -iname "*.cc" > cscope.files
cscope -cb -i cscope.files -f cscope.out
ctags --fields=+i -n -L cscope.files -f tags
cqmakedb -s cq.db -c cscope.out -t tags -p -d
```

In Windows, follow these steps for C/C++ source code:

```cmd
cd codequery-web
md share
cd share
git clone https://github.com/ruben2020/codequery.git .
dir /b/a/s *.h *.hpp *.hxx *.hh *.c *.cpp *.cxx *.cc > cscope.files
cscope -cb -i cscope.files -f cscope.out
ctags --fields=+i -n -L cscope.files -f tags
cqmakedb -s cq.db -c cscope.out -t tags -p -d
```

Please replace the file patterns above with `*.java`, `*.py`, `*.rb`, `*.go` and `*.js` respectively for Java, Python, Ruby, Go, and other supported languages. Details can be found on the [CodeQuery](https://github.com/ruben2020/codequery) project page.


## How do I run codequery-web?

### Method 1: Using Python directly

1. Create and activate a Python virtual environment:

```bash
python3 -m venv venv
source ./venv/bin/activate
# On Windows: .\venv\Scripts\activate
```

2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Start the application:

```bash
# Using the default ./share folder:
python wsgi.py

# Or specifying a custom path to the share folder:
python wsgi.py /path/to/my/project/share
```

Then open your browser and navigate to: `http://localhost:5000` (or `http://127.0.0.1:5000`).

### Method 2: Using Gunicorn (Production WSGI Server)

```bash
gunicorn --workers 3 --bind 0.0.0.0:8000 wsgi:app
```

Then navigate to: `http://localhost:8000`.

### Method 3: Using Docker Compose

```bash
docker-compose up --build
```

Then navigate to: `http://localhost:8080`.


## How to search and browse code?

### 1. Folder Browser & Navigation Bar
* Open the root directory or subdirectories to view source code files and folders.
* Every folder browser page and file contents page includes an address bar at the top, just below the navigation links.
* Each folder level in the address bar is a clickable hyperlink that allows you to instantly jump back to any parent folder level.

### 2. Search Query Form
* Navigate to the **Search Query** page.
* **Search term**: Enter the symbol or identifier to query.
* **Path filter**: (Optional) Restrict search to specific subdirectories or file patterns (e.g. `cli`, `gui`).
* **Search type**: Choose from 11 specialized CodeQuery query types (Symbol, Function definition, Class/struct, Inheritance, Call graphs, etc.).
* **Exact match**: Check to enable exact matching (uncheck for fuzzy match).

### 3. Search Results Table
* Displays matching symbols, source file paths with line numbers, and formatted line preview snippets.
* The file path column displays paths relative to the project root (`share/`), omitting redundant parent path prefixes.
* Clicking any result link opens the file viewer scrolled directly to the targeted line.

### 4. Syntax-Highlighted Code Viewer
* Displays source code with syntax highlighting for C/C++, Python, JavaScript, Go, Java, C#, and Markdown (`.md`).
* Every identifier / symbol in the code viewer is automatically wrapped in a clickable hyperlink that searches for that symbol in the database.
